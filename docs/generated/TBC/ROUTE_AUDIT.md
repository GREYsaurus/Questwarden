# Route audit

Generated by `tools/build.ps1 routes` (tools/src/RouteAnalyzer.cs). Do not edit by hand.

Every race/class route is walked step by step. **Model level** comes from the XP model: QuestieDB's TBC quest XP for each turn-in (support/QuestXP/xpDB-tbc.lua), the post-2.3 XP-to-level table, plus an ASSUMED kill XP of half the quest XP (no rested, discovery, group or dungeon XP; dungeon quest turn-ins add nothing). `level`/`grind` steps lift it to their level. It is a planning estimate, not a measurement. Distances are straight lines in zone-map percent, comparable only within the same guide. Method and limits: `docs/ROUTE_OPTIMIZATION.md`.
